## 🏪 Apresentação

A Batista Burger nasceu para transformar a fome em um momento de puro sabor! 🍔❤️ Aqui, cada mordida é uma experiência deliciosa, com hambúrguer suculento, ingredientes irresistíveis e acompanhamentos que deixam qualquer refeição ainda melhor.

Seja para matar aquela fome do dia ou para aproveitar um lanche especial, temos a combinação perfeita para você: um X-Burger saboroso, batatas fritas crocantes e um refrigerante bem gelado para completar o pedido.

Batista Burger, seu desejo de comer bem começa aqui! 🍟🥤

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura da página.
- **CSS3:** estilos e identidade visual da loja.
- **JavaScript:** perguntas sobre as quantidades, cálculos e apresentação dos resultados.

## ▶️ Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no computador.
3. Abra o arquivo `index.html` no navegador.
4. Clique no botão **Simular compra**.
5. Informe as quantidades solicitadas para cada produto.
6. Confira o resumo da compra apresentado na tela.

Não é necessário instalar bibliotecas adicionais.

## 📚 Dificuldades e aprendizados

**Dificuldades encontradas:** minha principal dificuldade foi conectar a pasta do projeto ao GitHub e enviar os arquivos para o repositório, pois achei o processo um pouco complicado e confuso no início. Também tive algumas dificuldades com os códigos HTML, CSS e JavaScript, porque ainda não tenho muita experiência com programação e estou aprendendo a utilizar essas tecnologias.

**O que aprendi:** aprendi um pouco mais sobre cada tecnologia utilizada no projeto, principalmente sobre o GitHub. pois tinha muita dificuldade com o mesmo, Consegui entender melhor como criar um repositório, enviar meus arquivos e deixar o projeto disponível na internet. Também aprendi um pouco mais sobre HTML, CSS,a qual tambem medoiam a cabeça, o JavaScript ja tinha mais afinidade e foi o que mais me dei bem,consegui colocar em prática o que estudei durante o desenvolvimento da loja. Foi uma experiência importante para ganhar mais conhecimento e confiança na hora de criar e publicar meus próprios projetos.
